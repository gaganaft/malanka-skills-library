# Malanka Skills Library

Публичная библиотека редакционных AI-скиллов Malanka. **Основной способ работы — использовать нужный скилл прямо из обычного чата ChatGPT, без установки.** Никакие Git, Python или Xcode для этого не нужны, если ChatGPT может прочитать публичные страницы GitHub.

| **Malanka Teleprompter Writer** | тексты новостей для суфлёра | [README](skills/malanka-teleprompter-writer/README.md) · [SKILL.md](skills/malanka-teleprompter-writer/SKILL.md) |

## Как пользоваться — основной способ

1. Откройте README нужного скилла в таблице и скопируйте оттуда **готовый запрос**. Ниже приведены такие же запросы для каждого скилла.
2. Вставьте запрос в **обычный чат ChatGPT**. Агент должен прочитать `SKILL.md` и необходимые связанные файлы из репозитория.
3. Убедитесь, что агент подтвердил чтение файлов, а затем отправьте материал и задачу. Если файлы недоступны, предоставьте их текст или попробуйте другую среду с доступом к GitHub.

**Важно:** это использование правил **в текущем чате**, а не постоянная установка. В новом чате отправьте запрос снова. Доступность публичного GitHub не гарантирует, что любой конкретный ChatGPT сможет открыть все файлы.

## Дополнительные варианты: постоянная установка

Если ваша среда поддерживает установку Skills, можно отдельно установить полную папку скилла (включая связанные файлы). Это необязательно для основного сценария. Подробности и технические варианты — в README каждого скилла. Установка может требовать специальных разрешений, сети и инструментов; чтение файла не означает успешной установки.

## Безопасность и доступы

Репозиторий публичный, но доступ к связанным Google-документам, таблицам и другим рабочим системам **не предоставляется автоматически**. Для Malanka Teleprompter Writer потребуется отдельный доступ к рабочим источникам. Не размещайте в публичном репозитории пароли, токены или закрытые материалы. Проверяйте факты и источники перед публикацией.
