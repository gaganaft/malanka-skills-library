# Malanka Skills Library

Библиотека редакционных AI-скиллов проекта **Malanka**. Скиллы предназначены для подготовки материалов в разных форматах и хранятся отдельно от инструментов других проектов.

## Скиллы

| Скилл | Для чего | Инструкция |
| --- | --- | --- |
| **Malanka Instagram Writing** | Публикации Instagram: Reels, одиночные изображения, карусели | [SKILL.md](skills/malanka-instagram-writing/SKILL.md) · [README](skills/malanka-instagram-writing/README.md) |
| **Malanka Shorts Writing** | Заголовки, описания и хэштеги YouTube Shorts | [SKILL.md](skills/malanka-shorts-writing/SKILL.md) |
| **Malanka TikTok Writing** | Короткие новостные сценарии для озвучки TikTok | [SKILL.md](skills/malanka-tiktok-writing/SKILL.md) · [README](skills/malanka-tiktok-writing/README.md) |
| **Malanka Teleprompter Writer** | Подготовка ежедневных новостей для суфлёра и рабочего сообщения ведущей | [SKILL.md](skills/malanka-teleprompter-writer/SKILL.md) |

Каждый скилл находится в отдельной папке `skills/<название>/`. Файлы `references/`, `agents/` и `evals/` (если присутствуют) являются частью пакета.

## Как начать без технических навыков

1. Откройте страницу нужного скилла по ссылке выше.
2. Если вы работаете в ChatGPT/Codex, где агент **имеет доступ к GitHub и умеет устанавливать skills**, скопируйте запрос ниже в новый чат, заменив `НАЗВАНИЕ-ПАПКИ` на имя папки из таблицы:

```text
Помоги подключить skill из публичного репозитория:
https://github.com/gaganaft/malanka-skills-library
Папка: skills/НАЗВАНИЕ-ПАПКИ/

Проверь, можешь ли ты читать репозиторий и устанавливать skills в моей текущей среде. Если можешь, прочитай SKILL.md и все необходимые файлы, установи полный skill и проверь его обнаружение. Не изменяй исходный репозиторий.

В отчёте отдельно укажи: доступ к файлам, полноту чтения, реальный результат установки и проверку активации. Если установка не поддерживается, не называй чтение файлов установкой — предложи понятный альтернативный способ.
```

3. Проверьте ответ: агент должен явно подтвердить **установку**, а не только чтение инструкции. Затем протестируйте skill в новом чате.

**Важно:** запрос в чате не гарантирует установку. Возможность зависит от конкретной среды, плана и разрешённых инструментов. Публичность GitHub означает, что файлы можно читать без приглашения, но не означает, что любой ChatGPT может устанавливать skills.

## Другие способы установки

- **ChatGPT с поддержкой Skills:** загрузите ZIP-архив **одной полной папки скилла** через доступный интерфейс создания/загрузки skills. Подробная пошаговая инструкция есть в README [Instagram](skills/malanka-instagram-writing/README.md) и [TikTok](skills/malanka-tiktok-writing/README.md).
- **Codex / совместимый Agent Skills клиент:** разместите полную папку в поддерживаемом каталоге skills и перезапустите сессию. Уточните путь в документации вашей версии клиента.
- **Одноразовое применение:** передайте агенту ссылку на SKILL.md и попросите использовать его правила в текущем чате. Это **не постоянная установка**.

## Версии и изменения

Редакционные правила каждого скилла определяются его `SKILL.md` и локальными ссылками на `references/`. Для Instagram и TikTok история версий и инструкции находятся в их README. При обновлениях сохраняйте весь каталог, не смешивая файлы разных версий.

## Ограничения и безопасность

Скиллы не заменяют фактчекинг и доступ к первоисточникам. Если исходный материал недоступен, агент не должен придумывать факты. **Malanka Teleprompter Writer** содержит ссылки на рабочие документы Google; публичный код не предоставляет прав на их чтение и запись. Для исполнения этого процесса требуются отдельные разрешения Google Docs/Sheets и актуальные документы/график.

Этот репозиторий публичный. Не добавляйте в него токены, пароли, персональные данные, закрытые редакционные материалы или секреты.
