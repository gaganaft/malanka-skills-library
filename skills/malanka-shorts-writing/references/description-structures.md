# Структуры описаний Malanka Shorts

## 1. Базовая форма

```text
[Кто/что/где] + [событие/изменение и ключевой факт]. [Причина, цифра,
контекст, реакция или юридический статус — в той мере, в какой подтверждены].

[Смысловая часть заголовка] / Новости
```

**Зачем:** первый абзац самостоятельно передаёт суть, а нижняя строка повторяет тему и рубрику для упаковки публикации. Указатель рубрики добавляй только когда рубрика известна.

## 2. Четыре рабочих сценария

**Оперативное событие:** место + событие → реакция / статус / последствия.  
Референс №5 (авария в Ганцевичах): отдельно указаны официальные данные и неизвестные последствия.

**Правило / экономика:** решение или проект → кого коснётся → конкретная ставка/сумма → статус нормы.  
Референсы №6 (проект транспортного налога), №23 (пошлина для электрокаров).

**История человека:** кто столкнулся с чем → что произошло → реакция / последствия.  
Референсы №18 (клиенты мебельной фирмы), №22 (отключение электричества).

**Объяснение явления:** необычный факт → откуда данные → научное/экономическое объяснение → граница уверенности.  
Референсы №17 (маркировка HAL), №21 (пресноводные медузы).

## 3. Конкретные приемы корпуса

- Начало с места: «В Минске…», «В Беларуси…», «В Кличевском районе…».
- Начало с субъекта и действия: «Минчанка предложила…», «Более 200 клиентов…».
- Две смысловые части: новость → контекст; часто связаны словами «однако», «при этом», «по данным», «по словам».
- Проверяемая конкретика: суммы, проценты, организации, названия городов, число пострадавших.
- Модальность: «могли задержать», «предположительно», «эксперты связывают», «официального подтверждения нет».
- SEO-строка с повтором заголовка и рубрикой; в единичном случае — хэштеги непосредственно в описании.

## 4. Что **не** является паттерном этой выборки

- Завершать каждый текст риторическим вопросом.
- Призывать лайкать, подписываться или писать мнение.
- Ставить 5–10 хэштегов в конец описания.
- Писать большой сценарий с драматической развязкой вместо аннотации.

## 5. Проверки по риску

**Риск повторить заголовок без фактов:** убедись, что первый абзац добавляет минимум два конкретных элемента: число, имя, место, объяснение либо значимое последствие.  
**Риск завысить определенность:** проверь слова «предположительно», «по данным» и юридические статусы.  
**Риск скопировать ошибки SEO-строки:** сделай чистый смысловой заголовок без хэштегов, один раз сгенерируй из него рубричную строку и сверь с оригиналом.

## 6. Длина

В проанализированном корпусе: основной абзац **31–55 слов**, медиана ~45, среднее ~44. Практический ориентир для новых публикаций — 35–55 слов; увеличивай только когда иначе теряется необходимая оговорка о статусе факта. Это свойство данной выборки, а не ограничение платформы.
