# Выполнение задания и форма выдачи

## Перед написанием — входной контракт

Проверь наличие хотя бы исходного материала и желаемой темы. Для достоверной публикации установи:

| Поле | Что нужно |
|---|---|
| Источник | Статья / официальный документ / сообщение участника / проверяемая новость |
| Событие | Главное новое обстоятельство |
| Статус | Подтверждено, заявлено, предположительно, предлагается, уже действует |
| География | Где и кого касается |
| Конкретика | Проверенная сумма, число, имя, дата, последствия |
| Рубрика | `Новости`, `Новости регионов`, `Горячий Комментарий` или пропуск |
| Пожелания | Сколько вариантов, обязательные слова, чувствительные ограничения |

Если фактологической основы нет, запроси источник; не сочиняй реальные события для публикации.

## Пять шагов

1. **Проверка источника.** Прочитай материал; отдели главный факт от комментариев, прогнозов и контекста. Подтверди спорное по оригинальному документу.  
   *Ключевая точка:* названия, числа и статус нормы. *Зачем:* ошибка становится масштабнее через короткий заголовок.
2. **Заголовок.** Сделай 2–3 внутренних варианта разными способами; выбери точный и понятный без обещаний сверх материала.  
   *Ключевая точка:* после прочтения описания обещание заголовка закрыто. *Зачем:* интрига без ответа выглядит обманом.
3. **Описание.** Напиши один фактологический абзац, ориентир 35–55 слов.  
   *Ключевая точка:* описание не превращается в реплику ведущего. *Зачем:* это отдельное поле YouTube.
4. **Упаковка.** Добавь 2–3 тематических хэштега в заголовок и отдельную SEO-строку с рубрикой при её наличии.  
   *Ключевая точка:* теги не подменяют ключевые слова и не дублируются в описании. *Зачем:* метаданные должны оставаться читаемыми.
5. **Контроль.** Проведи редакторскую сверку по `editorial-rules.md`, включая рисковые обвинения и острые темы.  
   *Ключевая точка:* источники каждой спорной детали. *Зачем:* краткость не отменяет доказательность.

## Форма ответа по умолчанию

```text
Заголовок YouTube:
[Заголовок] #тема #география #shorts

Описание YouTube:
[Один самостоятельный абзац, без ссылок-источников и без транскрипции]

[Смысловая часть заголовка] / Новости

Источники для редакции:
- [Название — подтверждаемый факт](https://...)
```

Если рубрика неизвестна, опусти строку `/ Новости` — не утверждай, что ролик относится к этой рубрике. Если пользователь просит только готовое поле, убери служебный блок источников из копируемого текста и дай его отдельно после.

## Изменения и варианты

- При просьбе «поменяй заголовок» верни **всю обновлённую публикацию** (заголовок, описание, рубрика), если прямо не попросили только фрагмент.
- При просьбе «дай 3 заголовка» дай три разных типа (прямой/вопрос/контраст), один базовый абзац и теги, подогнанные под каждый вариант.
- При запросе «без хэштегов» оставь смысловой заголовок; не заменяй теги случайными ключевыми словами.
- При загрузке готового текста исправляй ошибки, но сохраняй замысел и статус фактов; критические изменения объясни кратко.
- При запросе «только описание» не добавляй сценарий, тизер, планы съёмки и CTA.

## Критерий завершения

Готовый заголовок, короткое описание и нужная рубрика; факты сверены; заголовок не переобещает; хэштеги соответствуют сюжету; блок источников отделён от публичного текста.
