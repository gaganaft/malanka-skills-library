# Malanka Teleprompter Writer — ежедневные новости для суфлёра

Выполнить весь процесс последовательно: источник → подготовка текста → запись и проверка → определение ведущей → черновик сообщения. Не отправлять сообщение без отдельной прямой просьбы пользователя.

## Постоянные источники

- Новости за июль 2026: [ИЮЛЬ 2026](https://docs.google.com/document/d/1fSEvg13Wjlhho6WH0_dJuTMQs7SMdWpTAGV_HicAgaU/edit)
- Суфлёр: [текст_суфлер](https://docs.google.com/document/d/1weYbRRk7M94XMuT6n-UfshuQBgilXiJJficIeHmkjLY/edit)
- График: [ГРАФИК 2026](https://docs.google.com/spreadsheets/d/1Xbyojuu3ALUSXMx1KXptUT4fduCdgvzkJqg3qrt54Z8/edit)

Подключить навыки Google Docs и Google Sheets и соблюдать их инструкции для чтения, записи и проверки существующих файлов.

## 1. Выбрать сегодняшние новости

1. Определить текущую дату в локальном часовом поясе пользователя.
2. Сначала прочитать метаданные месячного документа и перечислить его вкладки.
3. Выбрать вкладку с названием формата `ДД_ММ день-недели`, совпадающую с текущей датой. Для 23 июля это `23_07 четверг`.
4. Читать только выбранную вкладку. Не брать тексты из соседних дат или вкладки `Рекламные тексты`.
5. Если вкладки на сегодня нет, ничего не записывать и сообщить пользователю.
6. Считать каждую новость парой «заголовок прописными буквами + следующий за ним основной текст». В суфлёр переносить основной текст без заголовка, ссылок, комментариев редакторов и служебных пометок.
7. Не включать материал с явной пометкой `без ведущей`.

## 2. Подготовить текст для чтения

Сохранять смысл, факты, порядок предложений и финальный вопрос. Исправлять только очевидные опечатки, пунктуацию и то, что необходимо для естественного чтения вслух.

Применять ко всем новостям:

- Всегда писать `ё`, когда она предусмотрена нормой: `ребёнок`, `ещё`, `жильё`.
- Всегда использовать длинное тире `—`. Сохранять дефис только внутри слов: `кто-то`, `по-прежнему`.
- Раскрывать цифры, проценты, денежные суммы, даты и сокращения словами в форме, удобной для произнесения. Не менять точное значение.
- Расставлять ударения в сложных и неоднозначных словах, географических названиях, именах, фамилиях и других именах собственных.
- Обозначать ударение заглавной ударной буквой: `срЕдства`, `БарановИчи`, `ходАтайство`.
- Если ударная буква и так должна быть заглавной, оставлять её заглавной и выделять только эту букву жирным средствами Google Docs: `**М**инск`, `**О**льга`.
- Не выделять жирным другие буквы или слова без отдельной причины.
- Не добавлять ударения механически во все слова: помечать только потенциально трудные места.

Перед записью перечитать каждый текст вслух мысленно и устранить неудобные для произнесения конструкции без стилистического переписывания новости.

## 3. Записать в «текст_суфлер»

1. Перед первой записью выполнить доверенное чтение существующего Google Doc согласно навыку Google Docs.
2. Прочитать конец документа и проверить, не добавлены ли уже сегодняшние тексты. Не создавать дублей.
3. Добавить новости в конец документа, не удаляя и не изменяя прежние материалы.
4. Размещать каждую новость одним цельным абзацем без заголовка и нумерации.
5. Между соседними новостями оставлять минимум четыре полностью пустые строки.
6. Сохранить оформление документа: обычный текст Arial 12 pt, выравнивание по ширине. Жирным делать только ударную букву, которая по правилам написания уже заглавная.
7. Использовать контроль ревизии, если он доступен, чтобы не затереть параллельные изменения.
8. После записи перечитать документ и проверить:
   - все сегодняшние новости добавлены ровно по одному разу;
   - заголовки и служебные пометки отсутствуют;
   - между текстами не менее четырёх пустых строк;
   - везде используется `ё`;
   - вместо тире стоит `—`;
   - числа удобно читать;
   - ударения и жирное выделение сохранены;
   - прежние тексты не изменены.

Считать файл готовым только после успешного чтения и этой проверки.

## 4. Определить ведущую

1. Открыть таблицу `ГРАФИК 2026`.
2. Выбрать вкладку текущего месяца, например `Июль 2026`.
3. Найти колонку с сегодняшней датой в строке `ДАТА ➡️`.
4. Брать имя только на пересечении этой колонки и строки `ВЕДУЩИЙ` в секции `НОВОСТИ`. Не использовать строки ведущих из `ГОРКОМ`, `ТИК-ТОК`, `СТРИМ ИТОГ` и других секций.
5. Сопоставить значение:
   - `Ерусалимская` → Катя Ерусалимская → https://t.me/jerozolim
   - `Ася` → Ася → https://t.me/klyachina
6. Если ячейка пуста или указана другая ведущая, не угадывать адресата; сообщить пользователю.

## 5. Подготовить Telegram-сообщение

Подготовить, но не отправлять сообщение выбранной ведущей. Не применять к Telegram-сообщению правило обязательного использования `ё`. Приложить ссылку на документ `текст_суфлер`.

Текст:

```text
Привет, суфлер готов
https://docs.google.com/document/d/1weYbRRk7M94XMuT6n-UfshuQBgilXiJJficIeHmkjLY/edit
```

В финальном отчёте указать:

- сколько новостей добавлено;
- что проверка суфлёра пройдена;
- кто сегодня ведущая;
- ссылку на Telegram выбранной ведущей;
- готовый текст сообщения.

## Остановиться без записи

Ничего не изменять и запросить уточнение, если:

- отсутствует вкладка с текущей датой;
- структура вкладки не позволяет надёжно отделить новости от служебных материалов;
- документ суфлёра или график недоступен;
- не удалось однозначно определить ведущую;
- запись или итоговая проверка завершилась ошибкой.
