# Протокол обнаружения и проверки

1. Зафиксировать дату/время и окно мониторинга в локальном времени. Для текущих событий выполнять реальный веб-поиск.
2. Начать с открытого поиска на русском и беларусском. Добавить польский, английский, украинский при международных сюжетах; использовать несколько разных формулировок.
3. Проходы: главная национальная повестка; региональные сообщения; официальные объявления и документы; профильные источники по жизни/экономике/медицине/образованию/транспорту; международные события и беларусы за рубежом; публичные человеческие/необычные истории. Проходы пересекаются и **не являются квотами**.
4. Искать дополнительные первоисточники по конкретным именам, месту, датам и документам. Не полагаться только на агрегатор.
5. Для каждого кандидата зафиксировать ID события, короткое нейтральное описание, ссылку, дату публикации, дату самого события, статус подтверждения и названия источников.
6. Объединять перепечатки; самостоятельные новые факты и последствия выделять отдельно. Фиксировать сомнительные или противоречивые данные.
7. По окончании провести проверку слепых зон: не исчезли ли крупные общественно-политические события; не ограничился ли поиск парой СМИ; проверены ли регионы и повседневные истории. Ничего не добавлять ради формальной пропорции.
8. Отчёт: широкая картина и маркированный дополнительный интерес для Instagram. Если найдено мало материалов, показать мало — не выдумывать число для достижения нормы.
9. История не подтверждена — сохранить в отдельном блоке «нуждается в проверке», не формулировать обвинения как установленный факт.
10. Не заявлять о полном охвате Telegram, закрытых соцсетей или непроиндексированных сайтов.
