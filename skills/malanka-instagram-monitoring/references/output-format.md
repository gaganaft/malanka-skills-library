# Редакторский отчёт мониторинга

## Шапка
Дата/время составления; проверенное временное окно и часовое пояс; языки; обзор покрытия/известных ограничений.

## Общая новостная картина
Список событий с коротким фактическим лидом. По каждому:
- **Событие / ID** — нейтральное название, география, что произошло.
- **Когда** — дата события и отдельно дата публикации, если они различаются.
- **Основная ссылка** и **другие источники** с рабочими URL.
- **Первичный источник/документ** (или «не найден»), источники независимой проверки.
- **Статус**: подтверждено / частично подтверждено / требует проверки; конкретное недостающее подтверждение.
- **Примечание** — обновление, существенная неопределённость, неясное число, противоречие.

## Дополнительные Instagram-сигналы
Отдельно отметить сюжеты из общей картины, где есть человеческая история, общественная дискуссия, региональность, практическая польза, необычность или доступное проверенное визуальное свидетельство. Написать **почему**, не обещая просмотры. Значимость для широкой общественной повестки — также основание для внимания.

## Контроль качества
Количество уникальных событий; охваченные типы источников; концентрация источников (описательно, без принудительного исправления); замеченные пропуски и недоступные каналы; источники, требующие проверки. Не выдавать обзор за полный охват интернета.

Никогда не смешивать неподтверждённые кандидаты с установленными фактами.
