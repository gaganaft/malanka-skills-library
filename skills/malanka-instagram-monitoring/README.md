# Malanka Media Instagram — мониторинг новостей

Этот скилл предназначен для **обнаружения и редакционной оценки** новостей, а не для написания постов. Разработан по материалам 222 Instagram-публикаций за 29.07–26.10.2026 и списку источников редактора.

## Использование
Запрос: «Выполни мониторинг за последние 24 часа по правилам malanka-instagram-monitoring, покажи общую новостную картину, источники, проверку, дубли и отдельно потенциально интересные Instagram-сюжеты».

Для узкой задачи можно указать регион или период. Не нужно заранее выбирать тематические квоты. Если поиск не запущен/недоступен, скилл не должен выдумывать новости.

## Файлы
- `SKILL.md` — обязательный рабочий протокол.
- `references/search-protocol.md` — метод обнаружения.
- `references/source-register.md` — примеры веб-источников и отдельно Telegram.
- `references/editorial-evidence.md` — выводы из исторического корпуса и ограничения.
- `references/output-format.md` — формат для редактора.
