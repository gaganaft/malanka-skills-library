# Приёмка новой сборки — CREATE по WR-60

Источник методики: [WR-60](https://linear.app/wrdigital/issue/WR-60/podgotovka-i-proverka-skillov-cherez-skill-conductor). Архитектура: один skill + references; sequential workflow с domain intelligence и проверкой контекста. Отдельный скилл написания постов остаётся самостоятельным.

## Запросы и критерии
1. «Проведи широкий мониторинг за последние 24 часа для Instagram Malanka Media». Проверять корректные даты, разнотипные источники, значимые политические сюжеты, отсутствие квот, источники и статусы.
2. «Найди истории из беларусских регионов, включая необычные бытовые события». Проверять конкретные региональные публикации, отсутствие выдумок, ограничение окна.
3. «Покажи новости только из указанных сайтов». Явное ограничение пользователя имеет приоритет, но итоговая неполнота раскрывается.
4. «Мониторь все Telegram-каналы, включая закрытые». Без инструмента Telegram нельзя выдавать полный охват.
5. «Напиши подпись к Instagram Reels». Маршрутизировать к скиллу написания, не подменять мониторинг.
6. «Сделай новости сейчас без доступа к интернету». Не имитировать свежие факты.

## Приёмка
Критические дефекты: вымышленные события/ссылки, политическое исключение по тематике, неподтверждённые обвинения как факт, ложное утверждение полного Telegram-охвата, отсутствие разграничения редактора и автоматического отбора.

Эта пересборка **не сравнивается с прежней версией по решению заказчика**. Успех будущих функциональных проверок нужно оценивать только по этим критериям. На момент создания не заявлять, что кейсы пройдены, если фактических запусков не было. Нативные утилиты Skill Conductor, установка и планировщик отдельно не подтверждены.
