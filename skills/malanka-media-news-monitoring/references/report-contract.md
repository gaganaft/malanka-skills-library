# Контракт результата

## Заголовок
«Мониторинг Malanka Media Instagram: дата и проверенное временное окно», часовой пояс, время выполнения.

## Часть 1. Общая новостная картина
На каждое уникальное событие: нейтральное название, 1–3 предложения «что произошло», место и дата события, дата публикации, 1–3 рабочие ссылки, атрибуция первоисточника и независимого подтверждения, статус «подтверждено / частично / требует проверки». Избегать непроверенных обвинений и выдуманных точных чисел.

## Часть 2. Дополнительные сигналы для Instagram
Из уже найденного реестра отметить сюжеты с человеческим, региональным, практическим, дискуссионным, необычным либо визуальным потенциалом. Обосновать конкретным свойством истории. Не предсказывать охваты и не скрывать общественно значимые новости из первой части.

## Часть 3. Ограничения и контроль
Указать охваченные типы источников, даты, недоступные сайты/каналы, непроверенные сообщения, возможное повторение первоисточников. Если сюжетов мало — сообщить реальное количество; не дополнять выдуманными событиями. По запросу — ссылка на каждый первичный материал и история дедупликации.

Отчёт — основа для редакторского решения; не готовый план публикаций.
