# Начальная карта источников

**Не закрытый перечень и не подтверждение актуальной работоспособности доменов.** Проверять происхождение, дату и доступность на каждом запуске.

Открытые беларусские медиа для поискового обхода: Зеркало, Наша Ніва, Радыё Свабода, Белсат, Reform.news, Позірк, Charter97, KYKY и другие по мере выявления. Региональные СМИ, включая Флагшток, местные издания и независимые ресурсы. Отдельно — отраслевые медиа об экономике, образовании, медицине, транспорте, культуре и повседневной жизни. Правозащитные организации, официальные документы/ведомства, международные медиа Reuters, AP, BBC, DW, польские, литовские, украинские СМИ по релевантности.

Разделять: **где найдено** / **кто первый сообщил** / **чем независимо подтверждено**. Источники могут ошибаться; не использовать жёсткое правило доверия по бренду.
