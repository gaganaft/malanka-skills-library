# Malanka Media Instagram — News Monitoring

Переносимый скилл для поиска и первичной редакционной проверки новостей Instagram Malanka Media. **Это новая сборка с нуля по методике [WR-60](https://linear.app/wrdigital/issue/WR-60/podgotovka-i-proverka-skillov-cherez-skill-conductor)** (режим CREATE); прежняя папка `malanka-instagram-monitoring` остаётся архивной и не используется как нормативный шаблон.

## Назначение
Дать редактору широкую новостную картину, включая важную политическую повестку и дополнительные типы событий, выявленные в истории Instagram. Никаких квот и автоматического редакционного отбора.

## Использование
«Проведи мониторинг новостного поля за последние 24 часа для Malanka Media Instagram. Покажи подтверждённые события, источники, спорные сообщения и сюжеты с дополнительным интересом для Instagram».

## Состав
`SKILL.md` — основной маршрут; `references/discovery-sop.md` — поиск и проверки; `references/source-map.md` — стартовые точки поиска и Telegram как отдельный контур; `references/editorial-context.md` — эмпирические основания; `references/report-contract.md` — формат отчёта; `references/acceptance.md` — тесты и границы проверки.

## Доступы и ограничения
Нужен реальный доступ к веб-поиску. Сам GitHub-файл не запускает поиск по расписанию; установка, автоматизация, полный Telegram-сбор и права доступа сотрудников проверяются отдельно. Не хранить секреты. Полный корпус и исходные сведения остаются во внешних исследовательских документах.
