# Словарь и нормы именования для редактора YouTube-новостей

**Статусы:** `К` — устойчиво наблюдается в корпусе; `Р` — рекомендуемая нормализация, требует согласования; `О` — спорно/нужно утвердить; `И` — исключение по собственному имени. При выборе между текущим официальным самоназванием и статистикой архивного написания **проверять актуальное название**, а не только частоту.

## A. Беларусь, люди, география

| Предпочтительная редакционная форма | Не использовать как обычное редакционное обозначение | Статус и уточнение |
|---|---|---|
| Беларусь, в Беларуси, из Беларуси | Белоруссия, в Белоруссии | `К`: Беларусь. Исключение — точная цитата/название объекта |
| беларус, беларусы, беларусов, беларусам | белорус, белорусы и др. | `К`: корень `беларус-` |
| беларуска, беларуски, беларуску | белоруска, белоруски | `К` |
| беларусский, беларусская, беларусское, беларусские | белорусский и формы в авторском тексте | `К`: 1 679 вхождений `беларусск-` против 28 `белорусск-` в подготовленном слое сценариев |
| в Украине, из Украины | на Украине | `К`: 99 против 0 в сценарном слое |
| Россия | РФ для обычного неофициального повествования | `Р`: РФ уместно в названиях, цитатах, документах; в устной речи часто лучше «Россия» |
| беларусско-польская граница | белорусско-польская граница в авторской речи | `Р`: исключения по цитате/названию |
| война России против Украины / российское вторжение в Украину | эвфемизм без субъекта там, где он важен | `Р`: выбирать по факту, времени и конкретному событию |

**Запрет на глобальную замену `белорус*` → `беларус*`.** Организации, официальные названия и цитаты не меняются по этому правилу. Из архивных примеров: **«Белоруснефть»**, **«Белорусский металлургический завод»**, **«Белорусские обои»**, канал **«Белорусский силовик»**, санаторий **«Белоруссия»**. Перед передачей названия в эфир уточнить точную форму существительного, юридическое имя и произношение.

## B. Имя, фамилия, должность

**Базовая запись человека:**

- `display_name`: полное написание по согласованному редакционному словарю/источнику;
- `role_at_event`: должность/статус **на дату события**, не только на дату выпуска;
- `short_reference`: фамилия или короткое обозначение в следующем предложении;
- `vo_pronunciation`: проверенная дикторская подсказка, **не** строка для экрана;
- `source_of_spelling`: откуда взята форма имени.

В информационной части впервые обычно назвать имя и фамилию, если человек не очевиден из контекста. При первом упоминании юриста, политика, медика, свидетеля или местного жителя уточнить **его функцию в истории**. В заголовке/тизере может быть только фамилия общеизвестной фигуры.

**Корпусные формы, не автоматически утверждённые для любых контекстов:**

| Человек / написание | Редакторское действие |
|---|---|
| Александр Лукашенко / Лукашенко | В архиве преобладает фамилия; при упоминании политического статуса руководствоваться отдельно утверждённой формулой, не менять её от материала к материалу |
| Светлана Тихановская / Тихановская | Проверить избранную редакционную русскую форму, не заменять самостоятельно на «Святлана Ціханоўская» и обратно |
| Павел Латушко / Латушко | Проверить функцию и наименование органа/инициативы на дату события |
| Николай Статкевич / Статкевич | Учитывать актуальный юридический и политический контекст |
| Дональд Трамп / Владимир Путин | Проверять должность по дате события, а не памяти о сегодняшней должности |
| Иностранные имена, польские/беларусские топонимы | Норму транслитерации/транскрипции согласовать, ударение проверить отдельно |

**Произношение:** в архиве встречаются внутренние заглавные гласные (`СлУцк`, `РадОслав СикОрский`, `ГрОдненский`) и другие подсказки. В чистом тексте и на экране — обычное имя (`Слуцк`, `Радослав Сикорский`, `Гродненский`); в дикторском поле — проверенное ударение и сложные звуки. Не думать, что любая заглавная гласная всегда верно расставляет ударение.

**Нерешённое:** единая система русской передачи беларусских/польских имён, склонение нетипичных фамилий, последовательность «Светлана»/«Святлана» и аналогичные случаи — см. `open-decisions.md`.

## C. Организации, медиа, инициативы

| Сущность | Варианты из корпуса | Рабочее направление |
|---|---|---|
| Правозащитный центр | «Вясна»; «Весна» | `Р`: «Вясна» как самоназвание; подтвердить официальную форму |
| Издание | «Наша Ніва»; «Наша Нива»; «Наша нива» | `Р`: «Наша Ніва», сохраняя `і` |
| Инициатива бывших силовиков | «Белпол»; «БЕЛПОЛ» | `О`: утвердить актуальную официальную капитализацию/латиницу |
| Государственное информагентство | БелТА; БЕЛТА | `О`: утвердить одну нормативную форму и произношение |
| Радиостанция/медиа | «Радио Свобода»; «Радыё Свабода» | `О`: определить, о какой языковой редакции речь, сохранить нужное самоназвание |
| Медиа | «Зеркало», «Белсат», «Еврорадио» | Проверять официальный бренд, падеж и контекст ссылки на источник |
| Телеканалы | ОНТ, СТВ | Можно добавить родовое слово «телеканал» при первом упоминании |
| Государственные ведомства | МВД, МИД, КГБ, МЧС, Следственный комитет | Уточнять страну, если она неочевидна; отличать название ведомства от работников |
| Организации с `белорус-` в имени | «Белоруснефть», «Белорусский металлургический завод» и др. | `И`: сохранять официальное имя, даже если обычное прилагательное в редакции «беларусский» |

**Стандарт упоминания источника:** в первый раз дать читабельное имя издания/инициативы, затем допустимо «издание», «правозащитники», «журналисты», если нет двусмысленности. Не писать «СМИ утверждают», когда известен один конкретный источник. Не ставить знак равенства между соцсетевым постом и независимо подтверждённым сообщением.

**Типографика:** собственные имена изданий и медиа, если требуют кавычек, заключать в «ёлочки»; сокращения ведомств и буквенные логотипы обычно без кавычек; официальные названия предприятий — согласно проверенной форме, без искусственного перевода.

## D. Политика и государственные органы

| Выражение | Нормативный принцип | Статус |
|---|---|---|
| Лукашенко | Имя/фамилия позволяют ясно назвать субъект действия | `К` |
| самоназначенный президент | Встречается в корпусе, но не доминирует | `О`: политическая формула требует утверждения |
| самопровозглашённый президент | Редкое употребление; не универсальный обязательный оборот | `О` |
| диктатор | Встречается в критически окрашенных сюжетах; факт/должность не заменяет | `О`: определить допустимые случаи |
| режим Лукашенко | Политическая характеристика, не синоним «МВД», «чиновники» и «администрация» | `О` |
| власти Беларуси, беларусские власти | Использовать при обобщении, но ведомство называть конкретно, когда известно | `Р` |
| силовики | Совокупность представителей силовых органов, когда нельзя/нецелесообразно уточнить | `К/Р` |
| милиция | Органы внутренних дел Беларуси; не заменять на «полиция» | `К/Р` |
| пропагандисты / провластные медиа | Для точно указанной редакционной деятельности/контекста; не приписывать любому госслужащему | `О` |
| политзаключённый / политзаключённые | С `ё`; источник признания и формулировка по фактическому контексту | `К/Р` |
| признанный «экстремистским» | Обязательно уточнять кем и в рамках какой классификации | `Р` |
| задержан / подозревается / обвинён / осуждён | Не использовать как взаимозаменяемые статусы | `Р`, обязательная проверка |

**Не путать:** «по версии властей» — атрибуция; «по данным правозащитников» — источник; «действительно совершил» — утверждение о факте. Оценочные слова требуют пропорциональности и не должны замещать ключевую информацию.

## E. Социальные роли и феминитивы

В корпусе есть: **авторка**, **журналистка**, **блогерка**, **директорка**, **президентка**, **тиктокерка**, реже **редакторка** и **косметологиня**. Это подтверждает совместимость феминитивов с существующим редакционным голосом. **Не** выводить из этого требование создавать любой феминитив по продуктивной модели.

`Р`: использовать понятные закреплённые формы, учитывая самоназвание и роль героини; не выводить гендерную принадлежность из фамилии. `О`: редакционный список «экспертка», «министрка», «психологиня», «политикиня» и формальные должности.

| Сокращение | При устном упоминании | Рабочий статус |
|---|---|---|
| США, ООН, НАТО | Общеизвестные; не обязательно расшифровывать | `К` |
| МВД, МИД, КГБ, МЧС | Уточнить ведомство какой страны, если неоднозначно | `К/Р` |
| ЕС | «Евросоюз» может звучать естественнее; нельзя менять термин там, где важна юридическая точность | `К/Р` |
| РФ, РБ | В обычной речи предпочитать «Россия», «Беларусь»; официальное полное название по контексту | `Р` |
| СБУ, ЕАЭС, БРСМ, ФСЗН, ШОС, ГКСЭ | При первом упоминании раскрыть или объяснить роль организации | `Р` |
| ЖКХ, ГАИ | Можно использовать для основной аудитории, если не создают двусмысленность | `К/Р` |
| БПЛА | В устной новости часто естественнее «беспилотник» или «дрон», если точность не теряется | `Р` |
| ИИ, AI, IT | Различать русское название явления, официальный бренд и отраслевое сокращение | `Р` |

При первом неочевидном употреблении модель: **понятное полное имя + сокращение**; дальше сокращение, если оно выгодно по ритму. Никогда не изобретать расшифровку по памяти. Фонетику произношения хранить отдельно от написания.

## H. Числа, даты, единицы

**Для ведущего:** в исходниках много надписей типа `30-го марта`, `41-летний`, `38-ми`, `14-ти`. Они отражают попытку подсказать произнесение, но графически неоднородны. `Р`: использовать орфографически аккуратный `script_clean` и отдельно `vo_cues`, где можно дать словесное произнесение сложного числа. Например, `14 сентября` → в `vo_cues` «четырнадцатого сентября», когда этого требует контекст.

- Статус числа: точное, округлённое, оценочное («около», «не менее», «более») — не менять при редактуре.
- Дата события ≠ дата заявления ≠ дата публикации. Относительные «вчера/сегодня» проверять к дате выпуска.
- Деньги: валюта и страна должны быть ясны. «Доллары» без уточнения допустимы только при явном контексте.
- Цены/проценты: конкретизировать базу («увеличилась на 20%» — относительно чего?).
- Единицы: километры, градусы, миллионы, часы и др. при первом упоминании должны быть очевидны; для голосовой версии не читать математические символы.
- Цитаты с чужими единицами и датами не «исправлять» без выделения пересказа.

## I. Орфография, кавычки, знаки

- **Ё** в авторском тексте: устойчивая практика, рекомендуем последовательно. Политзаключённый, жёсткий, ещё, всё. Имена собственные и точные цитаты не менять механически.
- **Кавычки:** основной вид `«…»`, для вложения `„…“`. Не смешивать `“…”`, `"…"`, `«…»` без причины.
- **Тире:** `—` для синтаксического тире. Диапазон чисел — `–` при необходимости; дефис `-` внутри сложного слова.
- **Прописные:** заголовки-плашки в отдельном поле могут быть полностью прописными, **обычный сценарный текст не должен** наследовать этот регистр.
- **Ненормативные формы в источнике:** не переписывать прямую цитату молча; пояснить нейтральным закадровым текстом.

## J. Нежелательные автоматические исправления

- «Белоруснефть» → «Беларуснефть» — **ошибка**.
- «Наша Ніва» → «Наша Нива» — может быть ошибкой собственного имени.
- `РадОслав` → `Радослав` без проверки произношения — допускается **только** для очищения графики; ударение сохраняется в отдельной дикторской записи.
- «обвинён» → «осуждён» — подмена юридического статуса.
- «по словам свидетеля» → «установлено» — повышение уровня проверки.
- «около десяти» → «десять» — искусственная точность.
- «пишут в соцсетях» → «все беларусы возмущены» — необоснованное обобщение.
