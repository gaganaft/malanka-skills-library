# Проект редакционного скилла YouTube News Editor

**Версия:** 0.1.0-draft • **Дата:** 11.11.2026 • **Статус:** публикуется как черновик, редакционно не утверждён.

Это самостоятельный пакет для редактора **русскоязычных многосюжетных YouTube-новостей**. Он составлен по архиву из 517 DOCX. Сфера применения намеренно ограничена YouTube-выпусками; другие продукты и их стратегии не включены.

**Читать в следующем порядке:**

1. `EDITORIAL_RESEARCH.md` — что установлено анализом, что предлагается как правило, что не решено.
2. `references/open-decisions.md` — редакционные нормы, требующие утверждения.
3. `SKILL.md` — основной исполняемый регламент для ассистента.
4. `references/tone-structure.md` — голос, структура, редактирование сценария.
5. `references/lexicon.md` — написания и словарь.
6. `references/qa-checklist.md` — предвыпускная проверка.
7. `references/corpus-evidence.md`, `audit/` — методика и подтверждающие наблюдения.

Следующий шаг — согласовать 21 открытый редакционный вопрос из `references/open-decisions.md`, зафиксировать принятые решения в справочниках и после проверки повысить версию. Публичное размещение этого черновика не означает утверждения стандарта.
