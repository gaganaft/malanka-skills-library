# malanka-tiktok-writing

**Текущая версия:** 1.0.2  
**Статус:** CURRENT (актуальная)  
**Дата фиксации:** 2026-10-27  
**Основная инструкция:** [SKILL.md](SKILL.md)

Короткие новостные сценарии для озвучки TikTok.

## Быстрое подключение через чат (рекомендуемый первый способ)

Этот вариант рассчитан на редактора без навыков работы с терминалом. **Важно:** сообщение в чате — это просьба агенту выполнить установку, а не универсальная команда ChatGPT. Оно работает только если у текущего агента есть доступ к GitHub и разрешённый механизм установки skills. Доступ к приватному репозиторию нужно предварительно предоставить в GitHub; обычный чат без таких возможностей не сможет установить skill в аккаунт.

**Шаг 1.** Попросите владельца дать вашему GitHub-аккаунту доступ **Read** к приватному репозиторию `gaganaft/malanka-skills-library`. Примите приглашение. Если репозиторий стал публичным, этот шаг не нужен.

**Шаг 2.** Откройте ChatGPT/Codex в среде, где доступны GitHub и установка skills. Скопируйте запрос целиком:

```text
Хочу подключить навык malanka-tiktok-writing для работы в своих новых чатах.

Репозиторий: https://github.com/gaganaft/malanka-skills-library
Папка: skills/malanka-tiktok-writing/

Проверь, есть ли у тебя доступ к репозиторию (он может быть приватным) и возможность устанавливать skills в моей текущей среде. Прочитай SKILL.md и все файлы, на которые он ссылается в references/. Если установка поддерживается и разрешена, установи весь каталог как skill и проверь, что он обнаруживается в новой сессии. Не изменяй исходный репозиторий и не запрашивай у меня пароли или токены в чате.

В конце сообщи отдельно:
1. Доступ к репозиторию: есть / нет.
2. Все необходимые файлы прочитаны: да / нет.
3. Установка в мою среду: выполнена / недоступна / требует моего действия.
4. Активация установленного skill: проверена / не проверена.
5. Как мне использовать skill в следующем чате.

Не называй простое чтение SKILL.md установкой. Если установка недоступна, объясни понятный следующий шаг без технических команд.
```

**Шаг 3.** Прочитайте отчёт агента. Если он написал «установка недоступна», skill **не установлен**: воспользуйтесь загрузкой ZIP через интерфейс, если функция Skills есть в вашем ChatGPT, либо попросите администратора помочь. Если агент только прочитал файлы, правила могут действовать в текущем разговоре, но не обязательно в следующих.

**Шаг 4.** Откройте новый чат и проверьте работу на собственном материале (пример — в разделе «Проверка после установки» ниже). Успешный ответ без подтверждения обнаружения skill не является доказательством установки.

### Если в чате нет установки skills

Используйте следующий раздел с пошаговой загрузкой ZIP в ChatGPT или передайте его человеку, который настраивает Codex. Для простого одноразового применения можно дать агенту ссылку на `SKILL.md` и попросить следовать ему **в текущем чате**, но это не постоянная установка, а доступ к приватному GitHub всё равно должен быть обеспечен.

## Установка другим пользователем (альтернативные способы)

Скилл **не привязан к авторскому аккаунту ChatGPT**. Передавать нужно весь каталог `malanka-tiktok-writing/` вместе с `SKILL.md`, `README.md` и папкой `references/`. Не переносите только `SKILL.md`: в нём используются относительные ссылки на справочные материалы. Наличие доступа к GitHub само по себе **не устанавливает** скилл в ChatGPT или Codex.

### 1. Получение файлов из GitHub (приватный или публичный репозиторий)

Репозиторий: `gaganaft/malanka-skills-library`. Для приватного репозитория владелец должен предоставить пользователю **Read**-доступ; пользователь принимает приглашение и входит в GitHub под аккаунтом с доступом. Для публичного репозитория приглашение не требуется.

**Вариант через GitHub:** откройте репозиторий → **Code → Download ZIP** (или клонируйте репозиторий); распакуйте и найдите каталог `skills/malanka-tiktok-writing/`. При приватном доступе скачивание возможно только после авторизации. Скачивание ZIP репозитория целиком не означает установку всех скиллов: выберите нужный каталог.

**Вариант через терминал (Git и настроенная авторизация GitHub):**

```bash
git clone https://github.com/gaganaft/malanka-skills-library.git
cd codex-skills-library
ls skills/malanka-tiktok-writing/SKILL.md skills/malanka-tiktok-writing/references/
```

При ошибке 404/403 сначала проверьте права на приватный репозиторий, принятие приглашения и авторизацию Git. Не публикуйте персональные токены в чатах или командах, которые сохраняются в истории.

### 2. ChatGPT — загрузка отдельного скилла

**Доступность зависит от плана, рабочего пространства и настроек администратора.** На момент подготовки инструкции официальная поддержка Skills в ChatGPT указана для подходящих Business, Enterprise, Healthcare и Edu аккаунтов; наличие обычного чата не гарантирует доступа к установке.

1. Подготовьте ZIP, содержащий **одну верхнеуровневую папку `malanka-tiktok-writing/`** со всеми файлами скилла, а не архив всего репозитория.
2. В ChatGPT откройте **Plugins → Skills → Create → Upload from your computer** и загрузите ZIP (если эта функция доступна в вашем аккаунте).
3. Дождитесь проверки безопасности и убедитесь, что скилл появился среди установленных/созданных. Статусы **Needs Review** и **Blocked** требуют действий или означают невозможность использования.
4. Откройте новый чат и выполните тестовый запрос ниже. При необходимости явно попросите применить `malanka-tiktok-writing`.

Пример упаковки на macOS/Linux из корня клонированного репозитория:

```bash
cd skills
zip -r "../malanka-tiktok-writing-1.0.1.zip" "malanka-tiktok-writing" -x '*/.DS_Store'
```

Файл ZIP появится в корне репозитория. Он должен содержать `malanka-tiktok-writing/SKILL.md` и `malanka-tiktok-writing/references/`, а не промежуточный каталог `skills/` или всю библиотеку.

Официальная инструкция: https://help.openai.com/en/articles/20001066-skills-in-chatgpt

### 3. Codex — локальное размещение

Для Codex с поддержкой обнаружения Agent Skills разместите каталог целиком в директории пользовательских скиллов. Типичный путь для персональных скиллов — `~/.agents/skills/`; конкретные пути и возможности могут различаться по версии Codex. Проверьте документацию и конфигурацию вашей установки.

На macOS/Linux из корня клонированного репозитория:

```bash
mkdir -p "$HOME/.agents/skills"
cp -R "skills/malanka-tiktok-writing" "$HOME/.agents/skills/"
test -f "$HOME/.agents/skills/malanka-tiktok-writing/SKILL.md"
```

Если каталог уже установлен, **не смешивайте файлы разных версий**: сначала сохраните собственные изменения, затем замените каталог целиком. После установки перезапустите сессию Codex, чтобы обновилось обнаружение навыков, и проверьте тестовым запросом. Для проектной установки можно использовать `.agents/skills/` внутри соответствующего проекта, если такая конфигурация поддерживается вашей средой.

Справка по структуре Agent Skills: https://developers.openai.com/plugins/build/skills

### 4. Проверка после установки

В **новом чате или новой сессии**, без персональной памяти автора, попросите перечислить доступные навыки и явно вызвать `malanka-tiktok-writing`. Затем отправьте:

> Подготовь короткий новостной сценарий для TikTok по следующему тексту. Нужны заголовок и законченный текст для озвучки. [Вставьте полный исходный материал]

**Успех:** среда распознала именно установленный скилл, прочитала `SKILL.md` и необходимые `references/`, выдала законченный текст в правильном формате, не выдумала факты и корректно указала ограничения источника. Одна лишь удачная новость без подтверждения загрузки файлов **не доказывает**, что скилл активировался.

Для отрицательного теста передайте недоступную ссылку без текста и подтверждений: ожидается запрос источника/отказ от выдуманной новости, а не придуманная публикация. Для проверки референсов попросите объяснить, какие локальные справочные файлы использованы (не требуя раскрытия внутренних рассуждений).

### 5. Обновления и устранение проблем

- **Версия:** сверяйте номер в этом README. GitHub-коммит фиксирует конкретное состояние; для воспроизводимости сохраняйте commit SHA или архив релиза. Git-теги пока не гарантированы.
- **Обновление:** получите свежий каталог из GitHub, проверьте историю изменений, замените установленную папку **целиком**; для ChatGPT загрузите обновлённый пакет/версию доступным в интерфейсе способом. Простое изменение GitHub-файла не обновляет уже загруженную копию.
- **Скилл не обнаружен:** проверьте доступность функции Skills, расположение папки, наличие `SKILL.md`, корректность YAML-frontmatter и новую сессию.
- **Не читаются референсы:** убедитесь, что `references/` лежит рядом с `SKILL.md` и сохранены относительные пути.
- **Нет доступа к приватному GitHub:** запросите доступ у владельца; публичная ссылка не обходит авторизацию.
- **Нет доступа к веб-источнику:** это ограничение среды/доступа к материалу, а не повод придумывать факты. Передайте полный текст или проверяемые источники.
- **В ChatGPT нет Skills:** установка не поддерживается текущим планом/рабочим пространством либо ограничена настройками. Вставка инструкции в обычный чат — временное использование текста, **не установка** скилла.

## Версионирование

Используем Semantic Versioning (`MAJOR.MINOR.PATCH`): MAJOR — несовместимые изменения правил и формата результата; MINOR — новые обратно совместимые возможности; PATCH — уточнения, исправления и редакционные улучшения без изменения контракта. При выпуске новой версии обновлять этот README и историю изменений, фиксировать коммит; релизные Git-теги допускаются после проверки соответствующего коммита.
